01设计原则

参考图提供的是信息结构和温度，不是材质。SleepDown 的页面靠层级、留白与玻璃采样建立家族感， 所以这里保留四象限的版式语言与"还有 N 天"的阅读节奏，把外观交回既有设计系统。

结构来自参考图

2×2 四象限、周条、大号倒计时、右侧天数——这些是用户一眼能懂的部分，保持不变。

材质来自 SleepDown

玻璃卡片采样页面 backdrop，无壁纸时同几何实色降级；前景色统一来自同一套对比度体系。

色彩只做标记

象限色仅用于标题下 3dp 短线和计数徽标底色（≤ 18% 透明度），不给整张卡片铺色。

三个必须守住的边界

边界做法
主操作只有一个页面右下角单一 FAB（主色蓝 + 白色加号），列表和卡片不放第二个主按钮。
不新增弹层材质表单用 CenterLiquidDialog，日期用 SleepDownPickerDialog，撤销条用既有 Alert 表面。
不写死单设备网格按内容宽度在 2 列 / 1 列之间切换；字号、触控区随系统字体缩放一起放大。

分区职责

① 顶栏：58dp，返回 42dp + 标题「计划」。不放操作，避免和分段控件抢注意力。
② 分段控件：玻璃胶囊 + 白色滑块，220ms 位移；两段等宽，切换不重建页面。
③ 周条：公历 7 天，今天用 2dp 描边，选中用实心蓝底；计数点表示该天有未完成待办（≥1 个即显示）。
④ 象限卡：最多 3 条 + 「还有 N 项」；计数徽标为未完成数量，完成数不计入。
⑤ 待办行：22dp 圆形勾选、2 行标题、12sp 元信息；逾期红色、今天中性、未来带日期与天数。
⑥ FAB：56dp，主色蓝渐变 + 白色加号；进入列表滚动时保持固定。

时间显示规则

Hero 数字
精确剩余，按秒刷新；单位字符 19sp，数字 36sp 等宽
单位省略
剩余 < 1 天时省略"天"，< 1 小时时省略"时"，永不显示 0 值单位
卡片天数
日历日差：今天 → 「今天」，未来 → 「还有 N 天」，过去 → 「已过 N 天」置底灰
跨零点
整页重算一次；秒级刷新只作用于 Hero，列表不逐秒重组
超过 999 天
Hero 正常显示，卡片数字不缩字号，宽度用弹性布局让出空间

Hero 不加卡片：大字压在壁纸上时使用与首页一致的软阴影保证可读性（HomeReadableText 同族规则）， 大数字的视觉重量不被玻璃表面削弱。

卡片右侧「还有 / 已过」为 11sp 三级色，数字为 22sp 主色蓝（过期转 38% 中性色）。 置顶项排列表首位并带「置顶」徽标，每年重复项带「每年」徽标。

必须逐项验收的状态

状态表现判定
无壁纸卡片变实色白 / #1C1C1E，几何、圆角、点击区不变降级只替换材质
无 Backdrop（Android 12 以下）同上，但保留所有状态与动画不出现黑色或透明卡片
待办 0 条四格「暂无待办」；周条无计数点；FAB 可用不出现空的大插图
象限 > 3 条显示 3 条 + 「还有 N 项」；N 为剩余未完成数点击进入该象限列表
已逾期元信息红色，「已逾期 N 天」N = 日历日差，不含今天
完成 / 撤销勾选动画 200ms → 划线 → 移除；撤销条 3 秒撤销后回到原象限原位
倒数日 0 条Hero 整体替换为「还没有倒数日」+ 说明，列表为空不留大号空白卡
倒数日已过期Hero 显示「已过 N 天」并淡化；卡片置底排序不被过期项打断
长标题待办 2 行截断；事件名 2 行截断，Hero 不挤压计时计时始终完整可见
平板 / 横屏内容区最大宽 720dp 居中，象限保持 2×2 不变形；列表卡片不拉满整屏宽度不出现超宽单行文本

07交互与动效

交互动效时长 / 曲线
分段切换滑块位移 + 内容 120ms 交叉淡化，不横向滑动整页220ms，cubic-bezier(.22,.9,.24,1)
勾选完成圆点填充 → 勾选路径绘制 → 标题划线 → 行高收拢200ms / 120ms / 180ms
撤销条底部升起 + 3 秒后下落，期间可点撤销in 240ms spring，out 180ms
打开表单沿用 CenterLiquidDialog 中心缩放，背景 blur 跟随组件既有曲线
日期选择SleepDownPickerDialog，无第二套壳组件既有曲线
秒数变化无缩放、无高亮、无逐位滑动，只换文本即时
列表增删animateItem 位移 + 淡入淡出240ms
减少动效（系统"移除动画"）时，只保留状态变化与布局，不保留过渡位移；撤销条寿命仍是 3 秒。

09与参考图的差异

参考图来自另一个产品（手绘便签风 + 兔子插画 + 五栏底部导航）。以下差异是刻意的，不是遗漏。

参考图本设计理由
手绘边框、纸张底色、兔子插画不采纳（P3 可选空态插画）与液态玻璃、动态壁纸体系冲突；插画需成套资产
周条含农历与节气（初十 / 霜降）改为公历 + 未完成计数点无农历数据源；四象限不按日期组织
「2026.10」月份大数字 + 「今」快捷取消页面没有按月浏览的语义
底部五栏（计划/视图/统计/倒数日/我的）并入首页 Dock 第三项「计划」不重构既有导航与转场
珊瑚色 FAB主操作蓝 #0A84FF主操作固定主色 + 白前景
「全部分类」筛选P2（分类表）先保证核心可用，避免一次性铺开
倒数日顶部居中「全部」大标题左对齐「计划」+ 分段控件两个功能共用一页，居中大标题会被挤占
右上角方块切换图标文字按钮「排序」个人版优先可读性
