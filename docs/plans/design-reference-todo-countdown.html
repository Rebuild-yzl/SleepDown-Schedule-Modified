01导航模型

按应用现在的结构：Dock 就是一级导航，设置也是 Dock 里的一页，所以待办与倒数日直接进 Dock，不做「计划」汇总页，也不做顶部分段控件。

模式Dock 顺序说明
普通（默认）课程 · 待办 · 倒数日 · 设置4 项 + 加号
并列今日 · 课程表 · 待办 · 倒数日 · 设置5 项，窄屏单项压到 ~48dp

交互约定

进入点 Dock 项直接切页，选中态立刻跟随；不打开新的 Activity，不做跨页转场。
返回页面内不设返回按钮（与设置首页一致）；系统返回手势回到「课程」。
加号放在 Dock 右侧，与首页加号同位置、同尺寸，点击打开新建表单。
不继承不做「待办 / 倒数日」页内分段；两页各自独立，互不嵌套。
这推翻了 v1 稿的「计划页 + 分段控件 + 独立 Activity」：多一层导航，也多一个返回按钮和跨页转场。按现有 Dock 结构直接插两页更简单，也符合用户对底栏的预期。

溢出每格最多 3 条，其余以「还有 N 项」进入该象限列表。

时间显示规则

Hero 计时
精确剩余，按秒刷新；34sp 等宽数字，单位 17sp
单位省略
剩余 < 1 天省略"天"、< 1 小时省略"时"，不显示 0 值单位
卡片天数
日历日差：0 → 「今天」，未来 → 「还有 N 天」，过去 → 「已过 N 天」并置底变灰
排序
置顶 → 未来按目标日升序 → 过去按最近在前
跨零点
整页重算一次；秒级刷新只作用于 Hero

行为

Hero显示最近一个未过期事件；没有未来事件时整块换成空态文案，不显示已过期事件的大数字。
点卡片编辑表单：标题 / 日期 / 时间（默认全天）/ 每年重复 / 备注 / 置顶。
长按快捷菜单：编辑 · 置顶 · 删除。
加号新建；日期用应用既有 Picker。
Hero 不加卡片也不铺玻璃：大数字直接压页面底色，靠字号和对比度撑住；壁纸场景可加文字软阴影（与首页文字规则一致）。

05状态

实现与验收按这张表逐项过。

状态表现判定
待办 0 条四格「暂无待办」，周条无计数点，加号可用不额外画大插图
象限 > 3 条3 条 + 「还有 N 项」，N 为剩余未完成数点击进入该象限列表
已逾期元信息红色「已逾期 N 天」N 为日历日差，不含今天
完成 / 撤销勾选 → 划线 → 移除，撤销条 3 秒撤销回到原象限原位
倒数日 0 条Hero 整块替换为空态文案，列表为空不留空白大数字
倒数日已过期Hero 不显示过期事件，卡片置底转灰排序不被过期项打断
长标题待办 2 行截断；事件名 2 行，不挤压 Hero 计时计时始终完整
大字体 1.3×象限卡改单列，行高随字号增长不出现两三个字换行
平板 / 横屏内容最宽 720dp 居中，象限保持 2×2；Dock 居中不拉满整屏
Dock 5 项（并列模式）单项宽压到 ~48dp，文字 10sp 不换行不横向滚动、不截断

06交互与动效

交互动效时长
切换 Dock 项选中态立即跟随；页面内容淡入，不做横向滑动140ms
勾选完成圆点填充 → 勾 → 划线 → 移除200ms
撤销条底部升起，3 秒后落下in 200ms / out 160ms
打开表单应用既有居中弹窗（材质与动画沿用组件）组件默认
秒数变化只换文本，不缩放不高亮即时
周条筛选选中的天切换填充；列表过滤120ms

08与参考图的差异

参考图本稿理由
底部五栏（计划 / 视图 / 统计 / 倒数日 / 我的）并入应用 Dock：课程 / 待办 / 倒数日 / 设置不重构导航；不新增「计划」汇总页
顶部分段「日程 / 待办」取消两页各自是一级页，不需要页内再分段
手绘便签、兔子插画、纸张底色材质仅示意本稿只定布局与交互；实现用应用现有材质
农历日期、节气公历 + 未完成计数点无农历数据源
「2026.10」「今」「全部分类」取消（分类 P2）四象限不按月组织；筛选先只做周条
珊瑚色 FAB主色蓝主操作固定主色
