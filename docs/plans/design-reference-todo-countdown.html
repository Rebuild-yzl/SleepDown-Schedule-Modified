01导航与 Dock

Dock 统一为 5 项，普通与并列模式相同；原「今日」项隐藏保留，代码和配置都不删除。

项顺序说明
视图1原「今日」日视图，Dock 名称改为「视图」
课程表2周视图，行为不变
待办3新增
倒数日4新增
设置5永远最后一栏

为什么能放 5 项

Dock 高度
46dp（原 54dp），圆角 23dp，内边距 4dp
单项宽度
50dp（原 56dp），选中滑块高 38dp、圆角 19dp
图标 / 文字
图标 18dp、描边 1.7dp；文字 9.5sp
加号
52dp（原 56dp），与 Dock 间距 8dp
宽度核算
5×50 + 8 + 52 = 310dp；360dp 窄屏加左右 16dp 边距仍有 18dp 余量

交互约定

进入点 Dock 项直接切页，选中态立刻跟随；不新建 Activity、不做跨页转场。
返回页面内不设返回按钮；系统返回从待办 / 倒数日回到「视图」。
今日项隐藏不删除：Dock 列表过滤掉它，HomeMode.Day、配置与跳转保留，去掉过滤即可恢复。
不继承不做页内分段；待办与倒数日各自独立。

倒数日 · 浅色　Dock 第 4 项选中
Hero 计时
精确剩余，按秒刷新；34sp 等宽数字，单位 17sp
单位省略
剩余 < 1 天省略「天」、< 1 小时省略「时」，不显示 0 值单位
卡片天数
日历日差：0 →「今天」，未来 →「还有 N 天」，过去 →「已过 N 天」并置底变灰
排序
置顶 → 未来按目标日升序 → 过去按最近在前
跨零点
整页重算一次；秒级刷新只作用于 Hero

行为

Hero显示最近一个未过期事件；没有未来事件时整块换成空态文案，不显示过期事件的大数字。
点卡片编辑表单：标题 / 日期 / 时间（默认全天）/ 每年重复 / 备注 / 置顶。
长按快捷菜单：编辑 · 置顶 · 删除。
加号新建；日期用应用既有 Picker。

04状态

状态表现判定
待办 0 条四格「暂无待办」，周条无计数点，加号可用不额外画大插图
象限 > 3 条3 条 + 「还有 N 项」，N 为剩余未完成数点击进入该象限列表
已逾期元信息红色「已逾期 N 天」N 为日历日差，不含今天
完成 / 撤销勾选 → 划线 → 移除，撤销条 3 秒撤销回到原象限原位
倒数日 0 条Hero 整块替换为空态文案，列表为空不留空白大数字
倒数日已过期Hero 不显示过期事件，卡片置底转灰排序不被过期项打断
长标题待办 2 行截断；事件名 2 行，不挤压 Hero 计时计时始终完整
大字体 1.3×象限卡改单列，行高随字号增长不出现两三个字换行
平板 / 横屏内容最宽 720dp 居中，象限保持 2×2；Dock 居中不拉满整屏
360dp 窄屏5×50 + 加号 52 + 间距仍放得下，文字不换行不横向滚动、不截断

05交互与动效

交互动效时长
切换 Dock 项选中态立即跟随；内容淡入，不横向滑动140ms
勾选完成圆点填充 → 勾 → 划线 → 移除200ms
撤销条底部升起，3 秒后落下200 / 160ms
打开表单应用既有居中弹窗，材质与动画沿用组件组件默认
秒数变化只换文本，不缩放不高亮即时
周条筛选选中天切换填充；列表过滤120ms

07与参考图的差异

参考图本稿理由
底部五栏（计划 / 视图 / 统计 / 倒数日 / 我的）应用 Dock：视图 / 课程表 / 待办 / 倒数日 / 设置沿用既有导航，只换名称与数量
顶部分段「日程 / 待办」取消两页各自是一级页
手绘便签、兔子插画、纸张底色不表达本稿只定布局与交互；材质按项目主题
农历日期、节气、月份大数字公历 + 计数点无农历数据源；四象限不按月组织
「全部分类」P2先只做周条筛选
珊瑚色 FAB主色蓝主操作固定主色
